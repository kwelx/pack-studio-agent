## Description

Pack Studio is a workspace where a person and an agent draft a small digital pack together. Six cards — title, theme, palette, and three levels — start as drafts. The React desk and the agent call the same Agent-Native actions: draft-pack, edit-card, approve-card, and export-pack. Editing a card returns it to draft. export-pack refuses to build the static page until every card is approved, and that page escapes every piece of text. Nothing is uploaded to a store.
